#🏢 ImóvelData - Sistema de Análise de Rentabilidade Imobiliária
Projeto desenvolvido para automoção de cálculos de rentabilidade imobiliária (Yield) e persistência de dados utilizando Python e SQLite, integrando análise com engenharia de dados.
## 🚀 Tecnologias Utilizadas 
* **Python** (Lógica de negócios e automação)
* **SQLite** (Banco de dados leve e integrado)
* **Pandas / Numpy** (Manipulação de dados analíticos)

## 📂 Estrutura do Projeto
* 'analise.py': Script principal de cálculo e inserção no banco de dados.
* 'data/': Armazenamento local de dados SQLite ('imoveis.db').
* 'notebooks/': Ambiente para exploração e testes em Jupyter.
